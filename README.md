# Risica website redesign

A proposed redesign of [risicadenver.com](https://risicadenver.com) for Risica, a Milanese pizzeria and wine bar in Denver's RiNo neighborhood.

It's one static page with no build step. Open `index.html` in a browser, or turn on GitHub Pages for this repo.

## Views

The page switches views with the URL hash:

- `#home`: homepage with hours, location, menu highlights, wine, chef, catering and sign-ups
- `#menu` / `#drinks`: full food menu and wine list (Nov 2026 menu)
- `#catering`: catering packages, à la carte menu and inquiry form
- `#visit`: location, hours and contact

## Still needed from Risica

Placeholders have a dashed outline on the page:

- Phone number, general email, parking directions, Instagram
- Reservation and Toast online-ordering links (the Reserve and Order buttons show a note until these are set)
- Catering lead time, delivery area and a name for the $55 buffet
- Somewhere for the catering form to send (it only shows a preview message for now)
